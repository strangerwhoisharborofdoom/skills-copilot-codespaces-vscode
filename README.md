# ⚔️ Clash of Clans Clone - Admin Edition

A browser-based clone of Clash of Clans featuring a complete administrator access system for advanced game management.

## 🎮 Game Features

### Regular Gameplay
- **Resource Management**: Manage Gold, Elixir, and Gems
- **Building System**: Place and manage various buildings on a 10x10 grid
- **Resource Production**: Gold Mines and Elixir Collectors automatically produce resources
- **Available Buildings**:
  - 🏰 Town Hall (500 Gold, 500 Elixir)
  - ⛏️ Gold Mine (200 Gold, 100 Elixir) - Produces gold over time
  - 🧪 Elixir Collector (100 Gold, 200 Elixir) - Produces elixir over time
  - 🏕️ Barracks (300 Gold, 300 Elixir)
  - 🔫 Cannon (400 Gold)
  - 🧱 Wall (50 Gold)

### 🛡️ Administrator Access
The game includes a powerful administrator panel with special privileges:

**Admin Password**: `admin123`

**Admin Features**:
- **Unlimited Resources**: Instantly add resources (Gold, Elixir, Gems)
- **Free Building**: Place buildings without resource costs
- **Instant Build**: Complete all building construction instantly
- **Unlock All**: Unlock all building types
- **Reset Village**: Clear the entire village and start fresh
- **Admin Stats**: View total buildings and admin status

## 🚀 How to Play

1. **Open the Game**: Open `index.html` in a web browser
2. **Select a Building**: Click on any building button in the "Buildings" section
3. **Place Building**: Click on an empty cell in the village grid to place it
4. **Manage Resources**: Watch your resources grow from production buildings
5. **Admin Access**: Click "🔐 Admin Login" and enter the password for special powers

## 🔐 Administrator Guide

### Accessing Admin Mode
1. Click the "🔐 Admin Login" button in the top-right corner
2. Enter password: `admin123`
3. The admin panel will appear with all special controls
4. Click "🔓 Admin Logout" to exit admin mode

### Admin Controls
- **+1000 Gold**: Instantly adds 1000 gold to your resources
- **+1000 Elixir**: Instantly adds 1000 elixir to your resources
- **+100 Gems**: Instantly adds 100 gems to your resources
- **Instant Build All**: Completes all building construction
- **Unlock All Buildings**: Makes all building types available
- **Reset Village**: Clears all buildings and resets resources

### Admin Benefits
- Place buildings without spending resources
- No resource limitations
- Full control over game state
- View detailed statistics
